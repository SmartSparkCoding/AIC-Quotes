Here you can find key information on how to use this API!

Main Endpoint

/quote

This is the main endpoint for all quotes. By using this endpoint without any parameters, the API will randomly select a quote and serve it to you.

The response to this API route (including all parameters) will be a JSON object containing the quote, act and character.

Example response:

            {
                "act": 3,
                "character": "inspector",
                "quote": "We don't live alone. We are responsible for each other."
            }

Parameters

?filter={FILTER HERE}

In this case, you NEED this at the start of the parameter, to tell the API what filter to apply.

There are 2 filters available, and you enter these in the area after the `-`:

  • act - you can use this to filter the act. As per the book, there are three acts in An Inspector Calls. Use the numbers, 1, 2 or 3.
  • character - you can use this to filter the character. You can use the names of the characters. They are: "inspector", "arthur", "sybil", "sheila", "gerald" and "eric".

?filter=act&act={act here}

This is pretty simple! Just put this after "/quote", and replace act here with your chosen act, from Act 1 to Act 3.

This will choose a random quote, from your specified act.

?filter=character&character={character here}

This is also decently simple. Just put this after "/quote", and replace "character here" with your chosen character!

The API will randomly then return a quote from your specified character.

The characters you can use are (case sensitive):

  • inspector
  • arthur
  • sybil
  • sheila
  • gerald
  • eric
